PRJ·01 — Agentic systems · Full-stack

Agentic Ad Delivery Optimization System

The problem. Ad campaign management is repetitive and reactive — humans tune budgets, targeting, and delivery long after the data already knew the answer.

The build. I designed an agentic orchestration system on the Model Context Protocol (MCP) for standardized tool integration, so autonomous agents can reason through delivery optimizations end-to-end. The backend is Java + Spring with API-driven, decoupled services processing simulated ad requests at sub-200ms latency — mirroring real omnichannel ad-serving platforms.

The product layer. A React dashboard for campaign management, shipped end-to-end, including resolving complex data-flow issues between the agentic workflow and the ad selection engine.

The infrastructure. Containerized with Docker, deployed on AWS (ECS, SQS, S3), with Terraform Infrastructure-as-Code and CI/CD pipelines achieving 95%+ test coverage.

PRJ·02 — Multi-agent AI · Research-grade

Agentic Medical Diagnosis System

The problem. A single LLM diagnosing in isolation is brittle. Medicine is a team sport — diagnosis improves when multiple perspectives challenge and refine each other.

The build. A multi-agent AI system for medical diagnosis implementing collaborative reasoning across three task types: ranking, multiple-choice, and open-ended diagnosis.

The interesting part. Agent coordination is adaptive, modeled on the Big Five Teamwork Model from organizational psychology — leadership, mutual performance monitoring, backup behavior, adaptability, and team orientation, translated into agent behaviors. This improved reasoning consistency by ~30%.

The rigor. Decision aggregation across agents, adaptive agent recruitment based on case difficulty, and systematic performance evaluation against ground truth.
